# SpeakEasy VR — Public Speaking Practice Room

**Team:** Lit Solo
**Track:** Open Innovation (Education)
**Event:** Summer of Code Fest 2.0, VIT Bhopal

## Problem
Public speaking anxiety affects up to 75% of students, yet most never get 
accessible, low-pressure practice before high-stakes moments like placement 
interviews or presentations.

## Solution
SpeakEasy VR is a private virtual practice stage built in Unreal Engine 5, 
where students rehearse in front of a simulated audience that scales from 
small to large. An AI coach (Google Gemini API) analyzes what users type 
about their topic or nervousness and responds with short, encouraging, 
personalized feedback.

## Tech Stack
- Unreal Engine 5.4 (Blueprint)
- VaRest plugin for HTTP/JSON handling
- Google Gemini API for AI-generated coaching feedback

## Status (Prototype)
- ✅ Core UI (text input, feedback button, response display)
- ✅ Full HTTP request pipeline to Gemini API (request construction, JSON 
     body, sending)
- 🔄 Response parsing and display (in progress)
- 🔄 3D stage environment (in progress)
